# DUO PARTY

한 화면에서 두 사람이 함께 플레이하는 로컬 2인용 모바일 파티 게임입니다. 현재 개발 모드는 **Push Arena**를 8라운드 반복합니다.

## 오프라인 앱 설치

DUO PARTY는 설치 가능한 PWA입니다. HTTPS로 배포된 주소를 Safari에서 한 번 연 뒤 `공유 → 홈 화면에 추가 → 추가`를 선택하면, 이후에는 Wi‑Fi 없이 실행할 수 있습니다. Android/Chrome에서는 화면의 `앱 설치` 버튼을 사용합니다.

개발용 `http://192.168.x.x` 주소는 iPad의 오프라인 설치에 사용할 수 없습니다. 서비스 워커와 오프라인 캐시는 HTTPS 또는 같은 기기의 `localhost`에서만 활성화됩니다.

## 실행

ES modules를 사용하므로 파일을 직접 더블클릭하지 말고 로컬 서버로 실행하세요.

```bash
npm install
npm run dev
```

브라우저에서 표시된 로컬 주소를 열고, 스마트폰/태블릿에서는 Vite가 표시하는 `Network` 주소로 접속합니다. 서버는 모든 LAN 인터페이스(`0.0.0.0`)의 5173 포트에 바인딩됩니다. 별도 설치 없이 Python이 있다면 `python -m http.server 4173 --bind 0.0.0.0`도 사용할 수 있습니다.

## 조작

- 터치: P1은 왼쪽 조이스틱/대시, P2는 오른쪽 조이스틱/대시
- 키보드: P1 `WASD` + `Space`(대시) + `Q`(아이템), P2 방향키 + `Enter`/`Shift`(대시) + `/`/`P`(아이템)

## Push Arena 전술 요소

- 공격을 맞을수록 넉백이 0~100%까지 누적되고 같은 공격에도 더 멀리 날아갑니다.
- 약 7초 간격으로 방패, 강대시, 순간이동 중 하나가 아레나에 등장합니다. 한 번에 하나만 소지할 수 있습니다.
- 15초마다 링 축소, 회전 장애물, 위험 바닥 중 하나가 발생합니다.
- 방패는 2.7초간 피해와 밀림을 줄이고, 강대시는 다음 대시를 강화하며, 순간이동은 위험 지역을 피해 중앙권으로 탈출합니다.

## 새 미니게임 추가

`js/games/`에 동일한 `start()`, `stop()`, `resize()` 생명주기를 가진 게임 클래스를 추가하고 `PartyManager`의 게임 목록 및 `app.js`의 게임 팩토리에 등록합니다. 파티 점수·라운드·소개·카운트다운·결과 화면은 미니게임과 분리되어 있습니다.
