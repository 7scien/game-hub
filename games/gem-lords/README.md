# 보석의 군주 (Gem Lords)

2–4명이 한 기기에서 즐기는 로컬 패스앤플레이 보석 수집·엔진 빌딩 게임입니다. HTML, CSS, vanilla JavaScript만 사용하며 서버, 로그인, 서비스 워커가 필요하지 않습니다.

## 기준 소스

이 폴더가 Game Hub용 보석의 군주의 기준 작업 위치입니다. 이후 게임 기능·데이터·UI 수정은 이 폴더에 직접 반영합니다.

## Game Hub에 넣기

이 `gem-lords` 폴더를 Game Hub의 `/games/gem-lords/` 위치에 그대로 복사하세요. 모든 실행 경로는 상대 경로입니다.

- 시작 파일: `index.html`
- 공통 Home 버튼: `../../shared/game-shell.js`
- 목표 점수·토큰 한도·예약 한도: `js/rules.js`의 `CONFIG`
- 카드 밸런스: `js/data/cards.js`
- 귀족 타일 밸런스: `js/data/patrons.js`

## 게임 구성

- 개발 카드: 1단계 40장, 2단계 30장, 3단계 20장 — 총 90장
- 보석 토큰: 다이아몬드·사파이어·에메랄드·루비·줄마노 각 7개
- 황금 토큰: 5개
- 귀족 타일: 10장 중 플레이어 수보다 1장 많게 공개
- 귀족 조건: 5장은 보너스 `3·3·3`, 5장은 보너스 `4·4`
- 카드 삽화: 보석 5종 × 단계 3종의 원본 환경화 15장
- 귀족 초상: 기존 작품을 복제하지 않은 원본 인물화 10장

GitHub Pages처럼 정적 파일을 제공하는 환경에서 바로 실행됩니다. ES 모듈을 사용하므로 로컬 파일을 더블클릭하기보다는 정적 웹 서버 또는 GitHub Pages에서 여세요.

## 저장

게임 중 우측 상단 `×`를 누르면 저장 여부를 선택할 수 있습니다. 저장을 선택하면 브라우저 `localStorage`의 세 슬롯 중 하나에 현재 게임을 보관하며, 시작 화면에서 원하는 슬롯을 불러올 수 있습니다. 기존 단일 저장 데이터가 있으면 처음 실행할 때 1번 슬롯으로 자동 이전됩니다.

새 게임에서는 2–4인 인원수를 고른 다음 각 플레이어의 이름을 입력할 수 있습니다.

시작 화면의 제목을 약 0.7초 동안 길게 누르면 이 기기에서 사용할 게임 이름을 수정할 수 있습니다. 사용자 제목은 별도 로컬 저장소에 보관되며 기본 제목으로 되돌릴 수 있습니다.

게임 상단에는 모든 플레이어의 점수, 보유 보석 6종, 영구 보너스 카드 5종이 항상 표시됩니다.

보석 공급처와 현재 플레이어의 금고는 실제 수량만큼 겹쳐 보이는 입체 토큰 더미로 표시됩니다. 영구 보너스는 보석별 미니 개발 카드 더미로 표시되며, 카드 수가 늘어날수록 겹친 카드 가장자리도 함께 늘어납니다.

개발 카드를 구매하면 선택한 카드가 해당 보석의 영구 보너스 카드 더미로 이동하면서 축소·적층된 뒤 다음 차례로 넘어갑니다. 기기에서 모션 감소 설정을 사용하면 이 애니메이션은 생략됩니다.

보석을 가져오면 선택한 토큰이 공급처에서 현재 플레이어 금고의 같은 색 더미까지 포물선으로 회전 이동합니다. 도착 직전에는 토큰 면이 수평으로 돌아온 뒤 기존 더미 위에 순서대로 쌓입니다.

토큰 중앙 상징은 아이보리 상판에 평평하게 인쇄된 형태로 표시됩니다. 획득 애니메이션은 복잡한 전체 더미를 복제하지 않고 가벼운 전용 토큰 하나만 GPU 변형으로 움직여 모바일에서도 끊김을 줄였습니다.

## 테스트

```text
node --test tests/game.test.mjs
```
