# 4단계 UI/UX 리뉴얼 결과

## 구현 범위

- 기존 게임 로직, 범용 57개와 전용 30개, 전체 증강 87개 유지
- Canvas 논리 경로와 렌더링 계층 분리 유지
- 양 대각선은 끝점과 중앙을 포함해 각각 7개 지점 유지
- 2.5D 나무 판, 입체 말, 교차점과 출발/도착 표식, 경로 미리보기와 목표 하이라이트
- 말뭉치 개수, 특수 말 아이콘, 보호막·좀비·광신도·사신·명사수·폭탄·화톳불·안개 상태 연출
- 결과를 먼저 확정한 뒤 표시하는 가변 윷 개수 투척 애니메이션
- 선택 카드 확대·광택·선택/퇴장 애니메이션과 긴 설명 스크롤 처리
- 플레이어 현황, 상태 이상, 특수 승리 진행도, 증강 상세 보기
- 증강 도감 검색 및 범용/시작/중간/마무리 필터
- 행동 안내, 선택 취소, 비활성 사유, 애니메이션 중 중복 입력 차단
- 모바일 접이식 플레이어 패널과 터치 목표 개선

## 자동 검증

- Vitest 단위·통합 테스트: 112개 (기존 109개 + 기본 윷 확률 전수검사 3개)
- Playwright Chromium E2E: 11개
- E2E 범위: 2인 최종 승리, 4인 시작, 1·6·12라운드 선택, 능력 대상, 갈림길, 탈락/승리, 저장 복원, 모바일 조작, 중복 투척 차단, 도감 검색/필터, 스크린샷
- 모든 E2E에서 브라우저 `pageerror`가 없는지 추가 확인
- Vite 프로덕션 빌드 및 단일 오프라인 HTML 빌드

## 수정한 안정성 문제

- 윷 애니메이션 전에 게임 결과를 계산하도록 순서를 고정해 연출과 로직을 분리했습니다.
- 애니메이션 중 결과·던지기 입력을 비활성화해 중복 처리 가능성을 차단했습니다.
- 새로고침 저장 E2E의 초기화 범위를 첫 진입으로 제한했습니다.
- Canvas 호버와 터치 판정을 화면 좌표에서 논리 노드로 안전하게 변환했습니다.
