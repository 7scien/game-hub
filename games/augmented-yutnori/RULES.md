# 1단계 세부 규칙 결정

원 사양에서 수치나 동작이 명확하지 않은 부분은 다음과 같이 일관되게 처리했습니다.

1. **분기 진입**: 우상단 또는 좌상단 분기점에 정확히 멈춘 말만 다음 이동에서 지름길을 고를 수 있습니다. 분기점을 지나치는 이동은 바깥길을 유지합니다.
2. **중앙 진행 방향**: 말은 중앙에 들어온 지름길의 진행 방향을 유지합니다. 말 객체의 `route` 값으로 방향을 보존합니다.
3. **중앙에서 업기**: 같은 소유자의 말은 중앙에서도 업힙니다. 이후 묶음은 이번에 이동을 시작한 말의 진행 방향을 따릅니다.
4. **완주**: 도착점까지 필요한 칸 수 이상이면 완주합니다.
5. **백도**: 대기 중인 말에는 사용할 수 없습니다. 첫 칸의 말이 백도로 이동하면 대기 구역으로 돌아갑니다. 표시된 첫 번째 윷가락 하나만 뒤집힌 경우 백도로 판정합니다.
6. **낙**: 활성화 시 한 번의 던지기가 약 6% 확률로 낙이 되며 이동 결과를 만들지 않습니다. 추가 던지기 기회도 만들지 않습니다.
7. **이동 불가 결과**: 해당 결과로 움직일 수 있는 말이 하나도 없으면 결과 버튼 선택 시 자동으로 넘기고 로그에 기록합니다.
8. **포획**: 도착 칸의 상대 말뭉치 전체가 대기 구역으로 돌아가며, 포획한 플레이어는 추가 던지기 한 번을 얻습니다.
9. **턴 종료**: 남은 던지기와 이동 결과가 모두 소진된 경우에만 턴 종료 버튼이 활성화됩니다.

# 2단계 증강 세부 규칙 결정

1. **선택 후보 안전성**: 실제 효과가 구현된 범용 증강 57개만 무작위 후보에 들어갑니다. 보유 증강과 `이의있음!`·`명탐정`으로 제외된 증강은 중복 등장하지 않습니다.
2. **혼돈 모드**: 각 선택 라운드마다 플레이어별로 연속 2회 선택하며, 첫 선택을 보유 목록에 반영한 뒤 중복 없는 새 후보 3개를 생성합니다.
3. **투척 변경 우선순위**: `손은 눈보다 빠르다`의 예약 결과 → `개돼지`의 도/개 선택 → `모 아니면 도` → 기본 무작위 투척 순서로 적용합니다. `낙 방지`는 이 처리 전에 낙 판정을 비활성화합니다.
4. **슬쩍!**: 저장된 미사용 결과의 윷가락을 직접 선택합니다. 변경된 윷/모에 따른 추가 던지기는 소급해서 주거나 회수하지 않습니다.
5. **선봉장**: 선봉장이 대기·완주가 아닌 판 위에 있을 때 모든 정상 이동의 절댓값이 1 증가합니다. 따라서 백도는 2칸 후진이 됩니다. 도깨비·포·폰의 특수 이동에는 적용하지 않습니다.
6. **천상의 보호막**: 선택 당시 같은 말뭉치 전체에 하나의 공유 보호막을 부여합니다. 말뭉치가 죽을 상황에서 모든 죽음을 막고 묶음 전체의 보호막을 소모합니다.
7. **보호 효과 순서**: 천상의 보호막 → 프랜드 실드 → 기본 죽음 순서입니다. 보호막과 프랜드 실드가 함께 있으면 첫 죽음은 전부 방지되고, 다음 죽음부터 한 말만 죽습니다.
8. **프랜드 실드 충돌**: 공격자와 살아남은 수비 말이 같은 칸에 함께 있을 수 있습니다. Canvas에서는 소유자별 말을 살짝 떨어뜨려 표시하며, 다음 이동 때 각자 정상적으로 이동합니다.
9. **시간 여행**: 현재 말이 실제로 지나온 경로 기준의 뒤쪽 판 칸을 선택합니다. 대기 구역은 대상으로 삼지 않으며, 도착 칸의 포획·보호 효과는 정상 처리합니다.
10. **도깨비**: 매 차례 도깨비 말마다 도 또는 백도 무료 이동을 한 번 사용할 수 있습니다. 이 이동은 저장된 윷 결과를 소비하지 않습니다.
11. **좀비**: 감염된 상대 말은 원래 소유자를 유지한 채 대기 구역으로 돌아가고 좀비로 변합니다. 감염을 시작한 플레이어 ID를 유지하며, 전체 말의 절반 이상이 그 감염 계보가 되면 승리합니다.
12. **포**: 현재 칸과 같은 직선 위에서 정확히 한 개의 말이 있는 칸을 넘은 뒤의 칸만 선택할 수 있습니다. 차례마다 포 한 기당 한 번 사용합니다.
13. **폰**: 낙을 포함해 실제 투척이 발생할 때마다 폰 혼자 도만큼 전진합니다. 일반 이동 결과로는 선택할 수 없으며, 자동 이동의 포획과 추가 던지기는 정상 처리합니다.
14. **사목**: 외곽 네 변과 두 대각선의 논리 경로에서 연속 네 칸을 모두 점유하거나, 판 위 한 칸에 네 말이 업히면 즉시 승리합니다.
15. **이벤트 우선순위**: 효과 엔진은 `before/afterThrow`, `before/afterMove`, `before/afterPieceDeath`, `onTurnStart/End`, `onRoundStart/End`, `checkVictory` 이벤트와 명시적 우선순위를 지원합니다. 윷판 회전·접기·안개·마커 상태는 `boardState`에 독립 보관합니다.

# 2단계 후속 구현의 모호한 규칙 결정

1. **과유불급**: 윷 6개의 앞면 수가 0/1/2/3/4~5/6이면 각각 모/도/개/걸/윷/탈락으로 판정합니다. 윷은 추가 던지기를 줍니다.
2. **게임 접어라**: 논리 경로는 바뀌지 않습니다. 화면 좌표를 반으로 접고, 접혀 겹친 칸은 포획·바둑처럼 물리 위치를 쓰는 판정에서 같은 칸으로 처리합니다.
3. **돌려돌려 돌림판**: 논리 경로는 유지하고 화면과 물리 위치 판정만 90도 단위로 회전합니다. 획득 시 1~3쿼터 회전하고 소유자는 1회 다시 회전할 수 있습니다.
4. **8톤 트럭**: 선택한 말뭉치는 현재 경로에서 방향이 꺾이거나 다른 말이 막는 직전까지 직선 이동합니다. 사용하면 남은 던지기와 이동 결과가 소모됩니다.
5. **블러핑**: 실제 결과는 모든 판정이 끝날 때까지 가립니다. 거짓을 한 명이라도 지적하면 결과가 사라지고, 진실을 거짓이라 지적한 플레이어는 각자 다음 차례를 쉽니다.
6. **죄수의 딜레마**: 둘 다 협력하면 각자 도, 한 명만 배신하면 배신자는 모·협력자는 1회 휴식, 둘 다 배신하면 둘 다 1회 휴식입니다.
7. **알까기와 윷을 잘 던져봐**: 로컬 환경에서 조작 가능한 힘 게이지로 판정합니다. 알까기는 목표 구간 적중 시 상대 말 하나를 죽이고, 윷 맞히기는 중앙 구간 적중 시 대상을 2회 쉬게 합니다.
8. **안개**: 소유자 이외의 현재 플레이어는 자기 말과 인접한 칸의 상대 말만 봅니다. 소유자의 차례가 두 번 종료되면 사라집니다.
9. **무임승차**: 올라탄 말은 숙주 말뭉치의 이동을 따라가며, 죽거나 별도 이동하면 연결이 해제됩니다. 선택 시 즉시 던지기 1회를 얻습니다.
10. **특수 승리 취소**: `취~소`는 기본 완주, 사목, 좀비, 소 뒷걸음질, 악보 조건을 포함한 모든 중앙 승리 선언을 무효화합니다. 조건을 다시 만족하면 다시 승리를 시도합니다.
11. **명사수**: 지정 시 현재 던지기 기회 하나를 소비하며, 다음 라운드 이후 소유자 차례 시작에 해당 논리 칸의 모든 말을 죽인 뒤 표식을 제거합니다.
12. **사신**: 라운드 종료에 그래프 최단거리 기준으로 가장 가까운 비소유자 말 쪽으로 한 칸 이동합니다. 도착 칸의 말을 죽이며 사신 자체는 말 죽음 판정 대상이 아닙니다.
13. **외톨이**: 다음 투척은 표시 윷가락이 아닌 윷가락 하나만 뒤집힌 표준 `도`로 고정합니다.
14. **이도류**: 두 개짜리 윷 두 쌍을 각각 던집니다. 두 윷가락이 모두 뒤면 개, 그 외에는 도이며 모는 생성하지 않습니다.

# 3단계 전용 증강 세부 규칙 결정

1. **전용 후보**: 시작/중간/마무리 전용은 각각 1/6/12라운드에만 등장하며, 각 시점에는 범용 증강도 함께 등장합니다.
2. **대각선 판**: 좌상단-도착과 우상단-좌하단 대각선은 양 끝과 중앙을 포함해 각각 정확히 7개 지점입니다. 논리 노드와 Canvas 좌표를 함께 보정했습니다.
3. **가변 윷 개수**: 3개 또는 5개 윷도 앞면 수 0/1/2/3/4 이상을 모/도/개/걸/윷으로 판정합니다. 표시 윷 하나만 앞면인 경우 백도가 됩니다.
4. **눈치싸움**: 최다 득표가 공동이면 공동 최다 증강을 모두 무효화합니다. 선택 결과가 확정되기 전에는 획득 즉시 효과를 실행하지 않으며, 살아남은 선택만 순서대로 획득합니다.
5. **말이오? 파티**: 함정과 보상은 한 번 발동하면 사라집니다. 함정은 설치 순서대로 사망/2칸 후퇴가 교대하고 설치자에게는 면역입니다. 보상은 추가 투척/공유 보호막이 교대합니다.
6. **모험가 파티**: 획득 라운드를 기준으로 8라운드 뒤 시작 시 해산하며, 이후 완주한 말 하나마다 해산 라운드를 1 늘립니다.
7. **중전마마**: 기본 목숨은 1입니다. 다른 아군 말의 완주마다 목숨 1을 얻고, 죽음 하나마다 목숨을 소모합니다. 전체 플레이어의 실제 투척 12회를 생존하면 승리하며 완주 칸으로 이동할 수 없습니다.
8. **괴물과 1성**: 괴물은 하나만 보유하고 완주할 수 없으며, 공격받을 때 죽지 않는 대신 목표 포획 수가 1 증가합니다. 1성은 같은 칸에 업힌 말들의 성급 합이 8 이상이면 승리합니다.
9. **잠깐!**: 지정한 말뭉치는 현재 라운드와 다음 라운드 동안 이동할 수 있으며, 지정 시점의 라운드 번호에 2를 더한 라운드부터 해제됩니다.
10. **폭탄돌리기**: 설치 6라운드 뒤 라운드 시작에 폭발합니다. 폭탄 말이 포획하면 포획된 말 중 하나와 그 소유자에게 폭탄이 넘어가며, 현재 소유 플레이어가 폭발로 탈락합니다.
11. **살인 윷놀이**: 모든 플레이어의 체력은 6, 증강 소유자의 포획 피해는 잡힌 말 하나당 2입니다. 체력이 0이면 즉시 탈락합니다.
12. **계획대로와 순위**: 자연 순위는 승자, 확정 순위, 완주 말 수, 판 위 말 수 순으로 계산합니다. 모든 플레이어의 순서를 정확히 맞힌 경우 예측자만 승리합니다.
13. **동메달**: 3인 이상에서는 3위를 고정합니다. 2인 게임에서는 존재 가능한 최하위인 2위로 고정합니다.
14. **독이 든 성배**: 사용 횟수 제한이 없고 사용할 때마다 현재 차례의 던지기 기회가 3 증가합니다. 같은 차례에 실제 모가 한 번이라도 나오면 탈락합니다.
15. **라스트 댄스와 메아리**: 라스트 댄스의 배율은 정상 이동에만 적용하고 차례 종료 후 탈락합니다. 메아리는 각 플레이어의 차례를 같은 상태 흐름으로 한 번 더 반복합니다.
16. **네크로맨서**: 부활 대상을 선택할 기회를 보장하기 위해 마지막 생존자가 미사용 네크로맨서를 갖고 있으면 자동 최종 승리를 잠시 보류합니다. 부활한 플레이어가 이기면 네크로맨서 소유자도 공동 승리합니다.
17. **취~소 충돌**: 애묘인·특수 말·자원·순위 예측을 포함한 모든 특수 승리는 중앙 승리 판정을 통과하므로 `취~소`가 있으면 무효화됩니다. 탈락과 고정 순위 자체는 승리 선언이 아니므로 취소되지 않습니다.
