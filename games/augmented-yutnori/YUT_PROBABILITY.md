# 기본 윷 확률 검증

## 코드 규칙

기본 게임은 윷가락 4개를 사용하며 각 가락의 `back` 상태를 `rng() < 0.5`로 독립 결정합니다. 따라서 낙을 끈 상태에서는 앞/뒤 16개 조합이 모두 같은 `1/16` 확률입니다.

- 뒤 0개: 모
- 뒤 1개: 도
- 뒤 2개: 개
- 뒤 3개: 걸
- 뒤 4개: 윷
- 표시된 첫 번째 가락만 뒤인 경우: 백도

기본 설정은 `useBackDo: true`, `useNak: false`입니다. 백도를 사용하면 뒤 1개인 네 조합 중 표시 가락 조합 하나가 백도로 분리됩니다.

## 기본 설정 분포

| 결과 | 조합 수 | 확률 |
|---|---:|---:|
| 도 | 3/16 | 18.75% |
| 개 | 6/16 | 37.50% |
| 걸 | 4/16 | 25.00% |
| 윷 | 1/16 | 6.25% |
| 모 | 1/16 | 6.25% |
| 백도 | 1/16 | 6.25% |

이 분포는 공정한 네 가락과 표시 가락 백도 규칙에 맞으므로 게임 로직은 변경하지 않았습니다.

백도를 끄면 백도 조합이 도에 합쳐져 도 25%, 백도 0%가 되며 나머지는 같습니다. 낙을 켜면 먼저 6% 확률로 낙을 판정하고, 나머지 결과의 절대 확률은 위 표에 94%를 곱합니다.

## 자동 테스트

`tests/yut-probability.test.js`는 0부터 15까지 모든 앞/뒤 조합을 전수 검사합니다. 백도 켬/끔의 조합 수와 백분율, 전체 조합 합계가 16인지 검증하므로 무작위 표본 오차가 없습니다.
