# 증강 윷놀이

한 기기 또는 서로 다른 기기에서 2~4명이 함께 플레이하는 Canvas 기반 윷놀이입니다. **기본 윷놀이, 증강 선택 시스템, 범용 57개와 전용 30개를 합친 증강 87개 전체**를 구현합니다. 오프라인 모드는 서버 없이 유지되며, 온라인 모드는 서버 권한 Socket.IO 방을 사용합니다.

## 실행

```bash
pnpm install
pnpm dev
```

프로덕션 빌드와 테스트:

```bash
pnpm test
pnpm test:e2e
pnpm build
```

온라인 로컬 개발(터미널 두 개):

```bash
pnpm dev:server
pnpm dev --host 127.0.0.1 --port 4173
```

온라인 베타는 GitHub Pages + Render Free 구성을 지원합니다. 무료 서버는 15분 동안 요청이나 WebSocket 메시지가 없으면 절전되며, 재시작 시 진행 중인 방이 사라질 수 있습니다. 첫 연결은 서버가 깨어나는 동안 약 1분 걸릴 수 있습니다.

온라인 전용 검증:

```bash
pnpm test:online
pnpm test:soak
pnpm test:e2e:online
```

GitHub Pages 등 정적 호스팅용 빌드:

```bash
pnpm build:pages
```

확률 근거는 [YUT_PROBABILITY.md](./YUT_PROBABILITY.md), 공개 배포 전 준비 절차는 [DEPLOYMENT.md](./DEPLOYMENT.md)에 정리되어 있습니다.

## 현재 구현 범위

- 2~4인 로컬 플레이와 무작위 순서
- 6자리 코드 온라인 방, 비밀번호·방장 승인, 준비 대기실, 강퇴·방장 이전·다시 플레이, 2~4인 서버 권한 플레이
- 개인 재접속 토큰, 중복 접속 교체, 명령 순서 번호와 중복 명령 방지
- 요청 속도 제한, 입력 크기 검사, 방별 트랜잭션 롤백, TTL 방 정리, health/readiness/metrics
- 개인별 비공개 증강 후보와 다중 플레이어 상호작용 라우팅
- 노드/연결 기반 외곽길, 각 7개 지점의 두 대각선 지름길, 중앙 교차점
- 도·개·걸·윷·모, 선택형 백도, 선택형 낙
- 윷/모 및 포획 시 추가 던지기
- 여러 이동 결과 저장 및 사용 순서 선택
- 업기, 말뭉치 이동, 상대 말뭉치 포획, 완주, 기본 승리
- 차례와 라운드 분리
- Canvas 말 이동 애니메이션과 반응형 UI
- 자동 로컬 저장 및 이어하기
- 1·6·12라운드 증강 선택과 혼돈 모드 2회 선택
- 범용 증강 57개, 시작 전용 13개, 중간 전용 9개, 마무리 전용 8개
- 기존 특수 말 5종과 김첨지·중전마마·괴물·1성·광신도·펠리컨·마라토너
- 즉시·공동 승리, 순위 고정/재정렬, 부활, 체력, 폭탄과 특수 자원
- 투표·블러핑·죄수의 딜레마 등 순차 로컬 상호작용 UI
- 접기·회전·안개·명사수·사신·화톳불·똥 등 실제 윷판 상태
- 알까기·윷 던져 맞히기의 조작형 미니게임
- 우선순위가 있는 효과 이벤트 버스와 공용 죽음·포획·승리 처리
- 증강 카드, 대상 선택창, 보유 증강, 남은 사용 횟수 UI
- 입체 보드·말, 경로 미리보기, 이동 가능 칸과 선택 말 강조, 칸 호버 정보
- 결과 확정 후 표현되는 가변 개수 윷 투척 애니메이션과 윷·모 보너스 연출
- 증강 도감 이름/설명 검색과 범용·시작·중간·마무리 필터
- 클릭 가능한 보유 증강 상세, 접이식 모바일 플레이어 패널, 44px 이상 핵심 터치 버튼
- 11개 Chromium E2E 시나리오와 데스크톱·모바일 스크린샷 검증
- Socket.IO 런타임 통합 테스트와 2인·4인·모바일 터치 멀티컨텍스트 Playwright E2E

전체 증강 87개는 모두 실제 효과와 UI가 연결되어 지정된 선택 라운드에 등장합니다. 상세 현황은 [AUGMENTS.md](./AUGMENTS.md)를 참고하세요.

세부 규칙 결정은 [RULES.md](./RULES.md), 온라인 구조와 프로토콜은 [ONLINE.md](./ONLINE.md), 승인 후 배포 순서는 [DEPLOY_CHECKLIST.md](./DEPLOY_CHECKLIST.md)에 기록되어 있습니다.
