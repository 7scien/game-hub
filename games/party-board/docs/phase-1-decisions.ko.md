# PHASE 1 확정 규칙·결정 기록

전체 원문 요구사항은 `full-game-spec.ko.txt`에 그대로 보존한다. 이 문서는 요구사항을 삭제하거나 바꾸지 않고, 구현 전에 확정해야 할 해석만 추적한다.

## 2026-08-26 확정된 PHASE 1 결정

1. **캐릭터 선택 방식** — 4명이 각자 자유롭게 선택하되 중복은 허용하지 않는다. 이미 선택된 캐릭터는 다른 플레이어가 선택할 수 없다. 실제 턴 순서는 캐릭터 선택과 무관하게 게임 시작 시 서버가 한 번 무작위로 정한다.
2. **재접속 신원** — PHASE 1은 같은 브라우저·기기의 Supabase Anonymous Sign-in 세션 기준으로 복귀한다. 다른 기기 복구와 PIN은 이후 별도 기능으로 미룬다.
3. **방장 이탈** — 일시 단절로는 방장을 넘기지 않는다. 자동 위임은 이후 추가할 수 있도록 `host_user_id`, Presence, `last_seen_at`을 분리해 두되 PHASE 1에서는 실행하지 않는다.
4. **갈래길 길이** — 각 갈래길은 정규 60칸과 별개인 15–20칸 우회 경로다. 정규길에서 시작해 정규길에 다시 합류하며 갈래길끼리 무한 루프를 만들지 않는다.
5. **최소 7칸 간격** — 원형 정규길에서 같은 종류 칸 두 개의 인덱스 거리가 `>= 7`이어야 한다.
6. **60번째 턴** — 60번째 플레이어의 주사위·이동·도착 칸 효과를 모두 해결한 후 결과 단계로 전환한다. 60턴에는 일반 미니게임을 실행하지 않는다.
7. **PHASE 1 미니게임 placeholder 보상** — 코인 보상 없이 placeholder를 확인하고 다음 글로벌 턴으로 복귀한다.

## 확정된 글로벌 진행 규칙

- 모든 플레이어는 20코인, 별 0개, 6칸 빈 인벤토리로 시작한다.
- 턴 순서는 게임 시작 시 한 번 무작위로 정하고 60턴 종료까지 유지한다.
- 일반 미니게임 시점은 글로벌 턴 6·12·18·24·30·36·42·48·54 종료 후다.
- 글로벌 턴 9의 칸 효과까지 끝난 뒤 최초 별 칸을 일반칸에 생성한다.
- 별을 실제로 구매했을 때만 별 칸을 다른 일반칸으로 옮긴다. 코인 부족 또는 구매 거절이면 이동하지 않는다.
- 글로벌 턴 21과 42의 칸 효과가 끝난 뒤 동료 칸을 생성한다.
- 글로벌 턴 60에는 미니게임 없이 최종 업적과 별 계산 결과 단계로 전환한다.
- 실제 Supabase 4인 동기화 테스트가 통과하기 전에는 PHASE 2를 시작하지 않는다.

## 이후 PHASE에서 확정할 충돌·누락

- 업적 공동 1위가 코인까지 같을 때 수상자와, 최종 별 개수가 같을 때 우승자 결정 규칙이 없다.
- 별칸은 “일반칸에 생성”되므로 일반칸 위 overlay인지, 해당 칸 종류가 별칸으로 일시 교체되는지 확정이 필요하다.
- 별을 40코인에 살 때 동료의 “모든 행동 2배”가 별 2개만 지급하는지, 비용도 80코인으로 만드는지 명시가 필요하다.
- 더블/트리플 주사위가 기본 주사위 2개의 합 전체를 2·3배 하는지, 특정 주사위 한 개의 눈만 배수 처리하는지 명시가 필요하다.
- `+1 주사위`와 더블/트리플, 대포알을 동시에 쓸 수 있는지와 아이템 중첩 순서가 없다.
- 보호권이 미사일·함정·동료로 배가된 손실을 모두 막는지, 한 효과의 여러 손실(코인+아이템)을 보호권 1개로 막는지 확정이 필요하다.
- 돌로 남은 인벤토리를 채우는 불이익의 발생원·등장 확률·돌 제거 방식이 정의되지 않았다.
- 대포알 15칸 이동이 이동 최다 업적에 포함되는지, 갈래길을 만났을 때 선택하는지 명시가 필요하다. 위치교환기만 제외된다는 문장만 있다.
- 동료칸에서 동료 획득자가 특수 미니게임에 지면 동료를 누가 얻는지, 혜택의 구체값이 없다.
- 동료의 “플레이어 3턴”이 해당 플레이어 자신의 다음 3회 행동인지 글로벌 3턴인지 명시가 필요하다.
- 이벤트의 보스 조우는 결과적으로 네 가지 불이익 중 하나이므로, 보스 자체 연출 외 추가 보상·전투가 있는지 결정이 필요하다.
- 공격 코인 감소량, 함정 손실량, 특수칸 아이템별 정확한 확률, 럭키 티켓 확률표가 없다.
